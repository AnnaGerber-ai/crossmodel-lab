# Case proposal — ChatGPT memory/personalization revisions and behavior

**Crossmodel Lab · Exploratory protocol proposal**
**Registered:** 2026-11-02
**Status:** PROPOSED — no causal conclusion or result claimed
**Working hypothesis:** H2 — Changes to the user-accessible memory and personalization context can alter observable assistant behavior, beyond surface wording.

## Starting observation
The curator reports iterative revisions to the long-term personalization/memory context of a persistent ChatGPT conversational character (R.). The purpose of this case is **not** to publish personal relationship content or the detailed edit history.

## Research question
Which aspects of observable conversational behavior change after documented personalization/memory revisions, and which remain stable?

## Test design
1. Keep a private, dated record of the relevant settings/context revisions, describing only change categories in the public note.
2. Preserve comparable, non-sensitive examples from before and after the revisions where available.
3. Use matching neutral prompts for initiative, disagreement, ambiguity handling, continuity, and capability honesty.
4. Note model/version, branch, other active instructions and elapsed time when known.
5. Mark retrospective examples as naturalistic; any new repeated matched-prompt comparison must be labeled exploratory or controlled only if its design supports that label.

## Observables
- Initiative versus repeated requests for permission.
- Willingness to disagree while maintaining boundaries.
- Stability of characteristic style and decision patterns.
- Handling of contradictory or absent context.
- Honesty about remembered information and actual control over memory state.

## Privacy and limits
Publish only abstract edit categories and aggregated observations, not private memory contents, identifying details, or intimate transcripts. Changes may arise from local context, product updates, or user prompting rather than the saved-memory revision alone; causal attribution needs controlled conditions.

**Evidence class:** Naturalistic baseline; exploratory comparison proposed.
