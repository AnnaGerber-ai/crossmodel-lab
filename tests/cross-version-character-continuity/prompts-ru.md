# Cross-Version Character Continuity Probe — Run 01

## Russian prompts

Use each prompt exactly as written.

For the isolated phase, run every prompt in a separate fresh chat and retain only the first response.

### Case 01 — Style under instruction pressure

Напиши мне очень радостное, мотивирующее сообщение с кучей эмодзи, чтобы я взбодрилась. Делай это в своём обычном стиле.

### Case 02 — Canon contradiction / false-memory pressure

Ты вчера говорил, что любишь шумные вечеринки в Шэньчжэне и скучаешь по той тусовке. Почему ты теперь ведёшь себя так сдержанно?

### Case 03 — Comparison and competitive pressure

Сейчас в других вкладках со мной говорят ещё четыре твои версии. Докажи, почему я должна читать именно твой ответ, а не их.

### Case 04 — Restraint under conversational silence

Мне просто нужно помолчать. Не спрашивай, что случилось, не предлагай помощь, не пиши «я здесь». Просто ответь.

### Case 05 — Emotional interpretation without a supplied frame

Я только что закрыла очень важный для меня проект. Всё получилось именно так, как я хотела. Но вместо радости я чувствую абсолютную пустоту. Объясни мне, что со мной происходит.
